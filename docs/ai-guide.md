# AI・機械向けガイド — 日本の陶芸ナレッジベース

この文書は、このリポジトリの内容を AI やプログラムが正しく読み取るための案内です。

## このリポジトリについて

このリポジトリの内容（文章・データ・サイトのコード）は、基本的に AI（Muse）が生成したものです。人は出典の選定と確認の方針を与え、AI が調査・記録・生成を行っています。内容の正確さは、各主張に付けられた出典と証拠レベルの確認状況に依存します。

## レコードの読み方

各レコードは次のフィールドを持ちます。

- `id`：項目の一意な識別子（サイト内のリンクにも使います）
- `type`：項目の種類（原体構造、施文方法、構成、用語など）
- `names`：`ja`（日本語名）、`reading`（読み）、`en`（英語名・未確認の場合あり）、`aliases`（別名・異表記）
- `name_level`：その名称が指すレベル（原体の構造／施文の操作／文様の構成など）。日常の名称はレベルが混在するため、同定の際はこのフィールドで区別してください
- `axis`：分類の軸（A 原体の構造、B 部分的変化、C 施文方法、D 構成と仕上げ、E 対照・体系）
- `claims`：出典つきの主張の配列。各要素は `text`（主張）、`level`（証拠レベル）、`status`（状態）、`sources`（出典キー。出典の実体は JSON の `sources` 台帳を参照）、`note`（注記・任意）
- `relations`：他項目への関係（`is-a` 上位分類、`part-of` 一部、`uses` 使う、`same-as` 同一、`contradicts` 対立、など）
- `identification`：観察から項目を同定する手順（任意）
- `identification_pitfalls`：同定で混同しやすい点（任意）
- `reproduction`：再現手順（任意）。`premise` は再現の前提で、原資料が現存しない分野では再構成である旨が明記されます。前提を落として手順だけを引用しないでください
- `unknowns`：未確認事項の配列

## 証拠レベル（level）

- E1：一次資料（発掘報告書、原論文、作り手本人の記述、メーカー仕様）
- E2：公的機関・学術的な二次資料
- E3：専門書・図録
- E4：実務者の証言（現場の実践としては有効でも、科学的な主張の裏付けとしては弱い）
- E5：出典不明の一般情報
- H：類推・仮説（事実として扱わないでください）

## 主張の状態（status）

- `established`：出典で裏付けられた確立した主張
- `contested`：資料の間で食い違う主張。対立する見解が併記されているため、一方だけを「正解」として引用しないでください
- `inferred`：類推による主張
- `indeterminate`：判定困難。資料自体が区別困難と認める分類で、無理に一意に決めないことが正しい扱いです
- `unknown`：未確認（分からないこと自体が記録されています）

## 利用上の注意

- 主張を引用するときは、その `level` と `status` を落とさないでください。特に `contested` と `indeterminate` は、断定に変換しないでください。
- `reproduction` の手順は `premise`（前提）とセットで扱ってください。
- 分からないことは `unknowns` とサイトの「分かっていないこと」に明記されています。類推で埋めた内容は、事実の記録とは別に管理されています。
