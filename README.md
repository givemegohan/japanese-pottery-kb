# 日本の陶芸ナレッジベース（公開サイト）

日本の陶芸に関する知識を、出典と証拠レベルつきで公開する静的サイトです。GitHub Pages で配信しています。

## トップページ

トップページは https://givemegohan.github.io/japanese-pottery-kb/ （このリポジトリの `index.html`）です。内容の一覧、サイト内検索、「AIに質問する」フォーム、AI に読ませる場合のベストプラクティスはトップページにあります。

## このリポジトリについて（AI 生成物）

このリポジトリの内容（文章・データ・サイトのコード）は、基本的に AI（Muse）が生成したものです。調査・記録・生成は AI が行い、人は方針と出典確認の基準を与えています。各主張には出典と証拠レベルを付けていますが、正確さはその確認状況に依存します。誤りの指摘や追加の出典は、Issue でお寄せください。

## 現在の掲載内容

- トップページ（index.html）：内容の一覧・サイト内検索・「AIに質問する」フォーム・AIに読ませる場合のベストプラクティス
- 器の基礎と暮らし（basics.html）：陶器と磁器の違い、電子レンジや食洗機の可否、安全、手入れと保管、贈答、価格の基礎（現時点で30件以上）
- 買う・選ぶ・贈る（buying.html）：作家もの・骨董を含む器の買い方・選び方・贈り方。見方と真贋、買う場所、価格と価値、贈る応用、購入後と手放す（現時点で25件以上）
- 縄文文様の分類（jomon.html）：縄文土器の「縄文」を原体・施文方法・文様の3層で分類した項目レコードと同定キー
- 産地・窯の一覧（wares.html）：日本の陶磁器産地（現時点で160産地以上）のレコードと産地地図（ピンは各産地の代表地点、色は六古窯／伝統的工芸品指定／拡張層の区別）
- 陶芸の系譜（history.html）：縄文土器から現代陶芸までの系譜と技術伝播を、学術論文を中心とする出典つきのイベントとして整理したもの
- 技法の一覧（techniques.html）：原料から仕上げまでの技法（現時点で90件以上）のレコード（定義・手順・出典つきの主張・代表産地）
- 陶芸家・保持団体の一覧（people.html）：制度的コア（人間国宝・文化勲章・文化功労者）と拡張層、保持団体のレコード（現時点で380件以上。出典つきの主張・系譜・技法と産地へのリンク）
- 窯・設備の一覧（kilns.html）：窯と設備（現時点で40件以上）のレコード（メーカー仕様を中心とする出典つきの主張、安全上の注意、市場の事実）
- 土の一覧（clays.html）：産地土・ブレンド種別・原料（現時点で45件以上）のレコード（出典つきの主張、市場の事実）
- 釉薬の一覧（glazes.html）：釉の種別と釉原料（現時点で100件以上）のレコード（出典つきの主張、市場の事実）
