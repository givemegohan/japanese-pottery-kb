日本の陶芸ナレッジベース

日本の陶芸に関する知識を、出典と証拠レベルつきで整理した公開データベースです。縄文土器から現代の陶芸まで、産地・技法・人物・系譜を横断して引けます。

このサイトとデータは基本的に AI（Muse）が生成しています。各主張には出典と証拠レベルを付け、資料が対立する場合は両論を併記しています。

AIに質問する

質問を書くと、このデータベースから関連するレコードを選び、出典つきで答えるための「質問文」を組み立てます。お使いのAIに渡して使ってください。

質問例：

「ChatGPTで聞く」は、質問文を入力した状態で ChatGPT を開きます（内容を確認して送信してください）。ChatGPT 以外の AI（Claude・Gemini など）では「文章をコピー」を押して、開いた AI に貼り付けて送信してください。回答は AI が生成します。数字や手順は、各レコードと出典で確かめてください。

AIに読ませる場合のベストプラクティス

このサイトは、人間だけでなく AI に読ませることも想定して作られています。上の「AIに質問する」を使うのが一番簡単です。自分の AI に直接データを読ませたい場合は、次の手順が確実です。

ベストプラクティスを開く
  1. まずガイドを読ませる。 AI・機械向けガイド（docs/ai-guide.md） に、レコードの形式・証拠レベル（E1〜E5、H）・主張の状態（確立／対立／類推／判定困難）の定義があります。最初にこの文書を読ませると、以降の回答の扱いが正確になります。
  2. HTMLではなく JSON を読ませる。 質問の対象分野の機械可読データ（縄文／産地／系譜／技法／人物／窯・設備／土／釉薬／器の基礎と暮らし）が、正本の構造化レコードから生成した機械可読形式です。ページの見た目ではなく、こちらを根拠に答えさせてください。
  3. 主張の状態を確認させる。 状態が「対立」の主張は、どちらか一方ではなく両論を併記させること。「判定困難」「未確認」や、証拠レベル E5（出典不明の一般情報）・H（類推）を根拠に断定させないでください。
  4. 出典つきで答えさせる。 各主張の sources は出典キーで、JSON 内の sources 台帳に名称と URL があります。回答には出典名を添えるよう指示してください。
  5. 再現手順は前提とセットで使わせる。 技法の手順（procedure）と縄文の再現欄（reproduction）には、前提注記（premise）として「再構成である」旨が書かれています。前提を落として手順だけを引用させないでください。
  6. 必要なレコードだけを渡す。 JSON 全文を一度に渡すより、このページの検索で対象レコードの id を特定し、そのレコードだけを抜き出して渡すほうが、速く正確に答えられます。
  7. 重要な数値は原典で確認する。 内容は AI 生成であり、誤りが混ざることがあります。年号・温度・配合などの数値を実務に使うときは、主張に付いた出典の原典で確認してください。

指示例（そのまま AI への指示例として使えます）：

https://givemegohan.github.io/japanese-pottery-kb/docs/ai-guide.md の定義に従って、
https://givemegohan.github.io/japanese-pottery-kb/data/technique-records.json から
「志野」に関する主張を答えてください。状態が「対立」の主張は両論を併記し、
各主張には出典名を添えてください。

このデータベースについて

項目レコード（構造化データ）が正本で、このサイトと JSON はそこから自動生成した派生物です。主張は出典のあるものだけを載せ、出典が食い違う場合は一方に寄せず両論を記録します。まだ分かっていないことは「未確認」として各レコードに残してあります。誤りの指摘や追加の出典は、GitHub リポジトリの Issue でお寄せください。
